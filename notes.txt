Nesta aula vamos executar o processo de validação programaticamente. Quando fazemos o patch de um restaurante,
inicialmente não temos uma instância de Restaurante, então não podemos fazer a validação logo de incício.

Primeiramente fazemos com que o controler tenha uma instância de SmartValidator

    @Autowired
    private SmartValidator validator;

Depois criamos um método para validação e o chamamos logo após o merge da propriedade recebida com a instância de
Restaurante.

O método de validação fica assim:

    private void validate(Restaurante restaurante, String objectName) {
        BeanPropertyBindingResult bindingResult = new BeanPropertyBindingResult(restaurante, objectName);
        validator.validate(restaurante, bindingResult);
        if (bindingResult.hasErrors()) {
            throw new ValidacaoException(bindingResult);
        }
    }

Após a validação, se o bindingResult tiver erros vamos lançar uma exceção que nós criamos, a ValidacaoException.
No momento essa exceção não está sendo tratada, então ainda não temos uma mensagem adequada caso ocorra um erro.
Vamos adicionar esse tratamento na próxima aula.
