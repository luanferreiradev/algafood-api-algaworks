Nesta aula fazer com que o resource bundle do bean validation seja unido com o do spring. Não é recomendado fazer, é
melhor separado mesmo. Inclusive, isso não muda a precedência, como vimos na aula anterior, sobreescritas do
ValidationMessages.properties continuam do mesmo jeito, apenas e um arquivo diferente.

Primeiro criamos um novo pacote dentor da pasta principal: core e dentro dele criamos o pacote validation
Dentro criamos a classe ValidationConfig com o seguinte método:

@Configuration
public class ValidationConfig {

    @Bean
    public LocalValidatorFactoryBean validator(MessageSource messageSource) {
        LocalValidatorFactoryBean bean = new LocalValidatorFactoryBean();
        bean.setValidationMessageSource(messageSource);
        return bean;
    }
}

Desta forma configuramos para que o ValidationMessageSource passe a usar o nosso message source do Spring.

Passamos também a classe Groups para o pacote core.validation.
